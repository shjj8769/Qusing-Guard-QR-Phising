# QshingGuard: QR 피싱 실시간 차단·신뢰 인증 시스템

> QR 스캔 즉시 AI 맥락 분석과 블록체인 무결성 검증으로 피싱을 **접속 전에** 차단하는 보안 서비스 기획

## 문제 정의

- 피싱·큐싱 범죄 2년간 약 2배 증가 (+99.3%, 2020–2022)
- 전체 온라인 공격 중 큐싱 비중 17%, 전년 대비 60% 이상 증가 (SK쉴더스, 2023)
- 기존 QR 보안은 **URL 접속 후에야** 동작하고, 정상 QR 위에 스티커를 덧붙이는 **물리적 변조**는 탐지하지 못함

## 기존 방식과의 차이

| 구분 | 기존 QR 보안 | QshingGuard |
| --- | --- | --- |
| 탐지 시점 | URL 접속 후 (사후 탐지) | URL 접속 전 (사전 차단) |
| 검증 요소 | 악성 URL 리스트 대조 | AI 맥락 분석 + 블록체인 무결성 |
| 물리 변조 대응 | 대응 체계 없음 | 블록체인 등록 이력으로 식별 |
| 신종 피싱 | 취약 | 위치 불일치 분석으로 차단 |

## 처리 흐름

1. **QR 스캔**: 위치 정보 포함
2. **보안 정보 수집**: URL · 위치 · 맥락
3. **MCP 보안 컨텍스트** 구성
4. **AI 이상 탐지**: Isolation Forest
5. **블록체인 무결성 검증**: 등록 이력 대조
6. **종합 판단**: 정상(Allow) / 의심(Warn) / 위험(Block), 결과는 수집 단계로 피드백
